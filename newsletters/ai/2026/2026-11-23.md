## Modelos novos, pesos abertos e arquitetura multimodal

### 1. Z.ai libera GLM-5.4 para assinantes do Coding Plan, ainda sem API pública documentada

**O que aconteceu (23/11):** a Z.ai anunciou o **GLM-5.4** para todos os assinantes do GLM Coding Plan. O anúncio indica nova capacidade de visão, melhor desempenho geral em programação e **50% mais cota semanal** que GLM-5.3 para os planos sujeitos a limites semanais. **Não há benchmark técnico, preço de API avulsa nem pesos de GLM-5.4 publicamente documentados** no material verificado; o acesso confirmado é pelo Coding Plan.

**Por que importa / aplicação:** merece avaliação em coding agents com entradas visuais (prints de bugs, interfaces e diagramas), mas ainda não é justificativa para substituir modelos de produção sem endpoint, avaliação independente, contrato de custo e SLA. Trata-se de liberação inicial restrita à assinatura.

**Fontes:** [Anúncio do líder da Z.ai (X, 23/11)](https://x.com/ZixuanLi_/status/2124719275864670681) · [AI.info — checagem do anúncio e da disponibilidade](https://ai.info/news/z-ai-glm-5-4-coding-plan-vision).

### 2. Upstage abre Solar Mini 4.5 Preview com 35B parâmetros totais e 3B ativos

**O que aconteceu (23/11):** o modelo **`solar-mini-4-5-preview`** foi listado no console e changelog da Upstage. É um MoE de **35B parâmetros totais/3B ativos**, contexto de **512 mil tokens**, até **128 mil tokens de saída**, raciocínio, saídas estruturadas e tool calling. A prévia custa **US$ 0,01/1 milhão de tokens de entrada** e **US$ 0,04/1 milhão de saída** (90% de desconto promocional), com retirada programada para **30/11** e lançamento geral planejado para **01/12**.

**Por que importa / aplicação:** candidato para testes de agentes econômicos de alta volumetria e roteamento de tarefas. A data de retirada da prévia exige pinning de modelo, testes de regressão e revisão de custos; ainda não implica desempenho comprovado fora da avaliação do fabricante.

**Fontes:** [Upstage — ficha técnica e preço](https://console.upstage.ai/docs/models/solar-mini-4-5-preview) · [Upstage — changelog de 23/11](https://console.upstage.ai/docs/resources/changelog).

### 3. Upstage oferece modelo de treinamento colaborativo com desconto, mediante opt-in

**O que aconteceu (23/11):** `solar-pro-4-contributor` entrou no changelog como variante do Solar Pro 4 com **70% de desconto** em troca da permissão de usar prompts e respostas para treinamento. **Por que importa / aplicação:** expõe o verdadeiro trade-off de preço versus confidencialidade. Em aplicações com dados de clientes, documentos fiscais ou código privado, o modelo mais barato pode não ser elegível; separar ambientes e estabelecer políticas de dados antes de ativar.

**Fonte:** [Upstage — changelog, Contributor mode (23/11)](https://console.upstage.ai/docs/resources/changelog).

### 4. Ant Group publica modelos abertos LingSante 3.1 para raciocínio clínico e visão

**Por que importa / aplicação:** é um sinal de especialização multimodal fora das APIs fechadas, com potencial para pesquisas e pipelines de documentos clínicos. **Não é validação de segurança, aprovação regulatória nem recomendação de uso diagnóstico autônomo**; exige testes e revisão clínica independente.

**Por que importa / aplicação:** amplia opções para inferência privada multimodal e pesquisa de otimização, mas o tamanho não se confunde com custo baixo. Antes de hospedar, calcular GPUs, memória, throughput e o custo efetivo por tarefa, além de verificar licença.

### 6. Thinking Machines Lab libera Inkling 2 Mini, MoE com transformer de camadas repetidas

É interessante para coding agents locais, testes de quantização e comparação entre qualidade, latência e observabilidade do processo decisório. Os números não são comparação controlada universal.

**Fontes:** [Thinking Machines Lab — apresentação técnica](https://thinkingmachines.ai/news/inkling-2-mini/) · [Pesos no Hugging Face](https://huggingface.co/thinkingmachines/Inkling-2-Mini).

## Dados, RAG, execução de modelos e FinOps

### 13. Amazon Textract Insights chega à disponibilidade geral para extração ancorada em evidências

### 14. AWS publica agent skill para avaliar e configurar cache KV distribuído

**O que aconteceu (20/11):** o **Agent Toolkit for AWS** ganhou um fluxo com skill que orienta um coding agent a medir a utilidade de **cache KV distribuído** em inferência auto-hospedada, dimensionar o ambiente com KVTrace e configurar integração com LMCache, vLLM/SGLang e ElastiCache. A AWS divulga potencial de até **40% de redução de custo** e **80% no time-to-first-token** em cenários específicos.

**Por que importa / aplicação:** contexto longo e recorrente de agentes provoca prefill caro. O ponto prático é medir hit rate e custo líquido antes de adicionar Redis/Valkey como nível compartilhado de cache. Atenção a isolamento entre tenants, hashes sensíveis e consistência de formato de KV; os ganhos não são garantidos.

**Fonte:** [AWS — Distributed KV caching agent skill](https://aws.amazon.com/blogs/machine-learning/cut-self-hosted-llm-cost-and-latency-with-the-distributed-kv-caching-agent-skill/).

### 15. SageMaker HyperPod lança gateway de inferência global entre clusters e regiões

**O que aconteceu (20/11):** o **Global Inference Gateway** foi apresentado como endpoint único para encaminhar requisições OpenAI-compatible entre clusters HyperPod, em uma ou várias regiões, com failover e autenticação **IAM/SigV4** por conexões privadas AWS PrivateLink.

**Por que importa / aplicação:** simplifica roteamento e aproveitamento de GPUs distribuídas, mas não elimina custo de tráfego, questões de residência de dados e políticas de roteamento. É alternativa para fleets de inferência em múltiplas regiões, não equivalente automático a um load balancer genérico de Kubernetes.

**Fonte:** [AWS — SageMaker HyperPod Global Inference Gateway](https://aws.amazon.com/blogs/machine-learning/introducing-amazon-sagemaker-hyperpod-global-inference-gateway-one-endpoint-across-regions-and-clusters/).

### 17. BigQuery ativa controle de política para impedir coleta de prompt analytics

**O que aconteceu (23/11):** a documentação do BigQuery estabelece, a partir de hoje, o mecanismo de **Organization Policy** com constraint **`constraints/gcp.disablePromptAnalytics`** para bloquear a ingestão de dados de prompts usados na análise de qualidade de recursos conversacionais. ## Sinal técnico da edição

As novidades mais acionáveis deste início de semana combinam **modelos compactos com raciocínio e multimodalidade**, **harnesses que avaliam agentes em situações realistas** e **infraestrutura que separa execução, memória, cache, identidade e autorização**. No mundo empresarial, os ganhos reportados vêm de processos delimitados, auditáveis e integrados à operação — não de autonomia irrestrita. Para equipes de engenharia, os experimentos de melhor custo/benefício são: comparar novos modelos em tarefas internas, testar avaliações sintéticas, medir cache KV com tráfego real e exigir controles por ferramenta.
