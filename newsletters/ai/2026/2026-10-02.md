# AI — Resumo diário — 02/10/2026

Janela principal: **01/10 a 02/10/2026**. Os sinais mais fortes ficaram em **voz em tempo real, workflows agentivos codificados, computer use, governança de MCP em escala e infraestrutura especializada para IA**.

## Microsoft lança nova geração de áudio para voice agents

A Microsoft lançou o **MAI-Transcribe-2-Streaming**, o **MAI-Voice-2.1** e o **MAI-Voice-2.1-Flash**.

O ponto arquitetural mais interessante é a possibilidade de o agente começar a **raciocinar ou chamar tools antes de o usuário terminar a frase**.

```text
áudio parcial
   ↓
transcrição parcial
   ↓
reasoning / tool call antecipado
   ↓
resposta
   ↓
voz
```

## GitHub Copilot passa a ter workflows multi-agent definidos em código

O GitHub colocou em public preview os **Dynamic Workflows** no Copilot CLI, Copilot app e Copilot SDK.

Em vez de deixar toda a orquestração para um modelo, o desenvolvedor pode definir em código quais etapas são determinísticas, quais usam agentes, quais executam em paralelo e onde existem checkpoints humanos.

**Impacto:** tarefas repetíveis e caras ficam mais previsíveis e observáveis.

## Copilot também ganhou computer use no Windows e macOS

O GitHub liberou computer use para permitir que o agente leia conteúdo visual, clique, digite, role e navegue entre aplicações desktop.

O caso mais relevante é **software legado e aplicações GUI-only que não possuem API, CLI ou MCP**.

```text
API / MCP
   ↓ se não existir
CLI
   ↓
Computer Use
```

## Uber mostra como MCP muda quando chega a milhares de tools

A Uber publicou a arquitetura do seu **MCP Gateway**, com mais de **800 servidores MCP e 5.000 ferramentas**.

A solução separa control plane e data plane. Um registry mantém ownership, schemas e catálogo; o Proxy Gateway executa chamadas e traduz MCP para protocolos existentes.

Outro problema identificado é o **context tax**: milhares de descrições e schemas não podem entrar em cada prompt.

**Impacto prático:** em empresas com muitos microserviços, MCP tende a precisar do equivalente a API gateway + service catalog.

## OpenAI anuncia novas depreciações

A OpenAI anunciou datas de remoção de modelos antigos de Codex e TTS.

**Impacto prático:** model lifecycle virou preocupação permanente de arquitetura. IDs de modelos não deveriam ficar espalhados pelo código; vale usar uma abstração por capability e um model router.

## Ai2 abre infraestrutura para treinar MoEs acima de 1 trilhão de parâmetros

A Ai2 lançou o **Olmo-core 3**, nova geração de sua infraestrutura open source para treinamento de Mixture-of-Experts.

**Por que importa:** open source em IA não é apenas peso de modelo; abrir o training stack permite estudar paralelismo, routing, comunicação entre GPUs e eficiência.

## Google colocou TPUs em órbita

O primeiro protótipo do **Project Suncatcher** entrou em órbita para estudar como TPUs comerciais se comportam diante de radiação, extremos térmicos e estresse físico.

O impacto prático imediato é baixo, mas mostra a pressão sobre energia, refrigeração e localização de compute.

## Brasil: IA entra diretamente no workflow fiscal e contábil

A Thomson Reuters apresentou o **Domínio IA**, integrado a módulos de folha, escrita fiscal e contabilidade.

O valor está em combinar modelo, dados do domínio, regras específicas e workflow real.

## Sinal do dia

A principal tendência é a transformação do agente em **runtime de software**, não apenas interface conversacional: workflow, contexto, tools/MCP, GUI fallback, identidade, autorização, observabilidade e infraestrutura.
