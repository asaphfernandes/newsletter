# Engenharia e Arquitetura — Resumo — 23/09/2026

Foco em boundaries, plataforma, segurança e modernização.

## Cloudflare Worker Previews

Cada branch ganha código, configuração, URL e observabilidade próprios; recursos stateful também podem receber namespaces separados. **Trade-off:** isolamento completo exige bindings separados para recursos account-level.

## EKS: autorização de pull por Pod

O pattern baseado no KEP 4412 reduz dependência da node role, aproximando identidade de runtime e supply chain no nível do workload.

## Google Secure Source Manager

Source control, Private Service Connect, Cloud Build, VPC Service Controls e CODEOWNERS mais granular aproximam código e CI/CD do mesmo security boundary.

## GitHub Copilot com OpenTelemetry

Sessões, chamadas de modelo e tool usage entram no mesmo modelo operacional de traces e spans usado em sistemas distribuídos.

## GitHub eleva baseline criptográfico do SSH

Remoção de RSA/SHA-1 e suporte a híbrido pós-quântico exigem inventário de build agents, appliances e bibliotecas antigas.

## AWS + OpenAI na modernização de legado

Reverse engineering com source-line traceability seguido de forward engineering torna a cadeia legado → requisito → implementação → teste mais verificável.

## Sinal da edição

A tendência comum é reduzir o tamanho do **boundary de confiança**: empresa → repositório → branch → Pod → agente.
