# Engenharia e Arquitetura — Resumo — 05/10/2026

Janela principal: **02/10 a 05/10/2026**.

## GitHub Apps: tokens stateless expõem assumptions escondidas

O GitHub concluiu o rollout de novos installation tokens stateless para GitHub Apps.

A mudança de formato expõe um erro recorrente de integração: consumidores tratam um identificador opaco como se seu formato fizesse parte do contrato.

```text
Errado
token = "string de 40 chars"

Correto
token = opaque credential
        + scope
        + expiration
```

**Impacto arquitetural:** credenciais, IDs e tokens externos devem ser abstraídos pelo significado semântico, não por representação física.

## Kafka: validar schema no CI não elimina drift em produção

A Confluent publicou um padrão de validar compatibilidade de schema em **dois boundaries**: CI e startup.

O CI valida o estado durante o build. Entre build e deploy, outra equipe pode registrar novo schema, mudar compatibility policy ou o serviço pode apontar para outro registry.

**Trade-off:** fail-closed evita incompatibilidade silenciosa, mas torna o Schema Registry dependência do startup.

## Modernização: nem todo legado precisa começar por reescrita

A AWS publicou uma arquitetura para executar Oracle sobre EVS/VMware Cloud Foundation usando FSx for NetApp ONTAP.

É um exemplo de **modernização por mudança de substrate**: primeiro muda infraestrutura, operação, DR e storage; depois, se fizer sentido, moderniza-se a aplicação.

**Trade-off:** menor risco de migração versus manutenção da complexidade e do custo de licenciamento de Oracle e VMware.

## Debugging: git bisect não precisa assumir distribuição uniforme

O trabalho **BISCEPTER** analisou milhares de bug reports e observou forte viés temporal: uma grande parcela dos commits causadores de bugs estava concentrada nos commits mais recentes.

Em vez de dividir apenas quantidade de commits, a abordagem divide **massa de probabilidade**.

**Impacto prático:** regression hunting automatizado em grandes repositórios pode reduzir builds e testes necessários.

## Sinal da edição

O padrão comum é **não confiar apenas no que foi validado anteriormente; verificar no boundary real**.
