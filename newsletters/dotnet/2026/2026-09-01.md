# .NET — Resumo semanal — 01/09/2026

Janela principal: última semana de agosto até 01/09/2026.

## .NET 11 entra em estabilização

A edição acompanhou a aproximação do RC1 e a consolidação das mudanças do .NET 11. **Impacto:** o foco começa a migrar de experimentação de previews para compatibilidade, performance e planejamento de upgrade.

## Visual Studio ganha custom agents

O Visual Studio passou a ampliar cenários de agentes customizados, permitindo instruções e ferramentas mais específicas ao fluxo do time.

## Debugger Agent

A integração de um agente ao debugging mostrou o IDE evoluindo de autocomplete para investigação assistida de estado, stack e causa provável.

## MCP em C#

O ecossistema .NET começou a ganhar suporte mais direto a MCP, reduzindo glue code para expor tools e integrar agentes a aplicações .NET.

## VS Code agent-first

Mudanças no VS Code reforçaram workflows em que o agente participa de edição, navegação e execução de tarefas, não apenas de chat.

## Depreciações do GitHub Copilot

A edição chamou atenção para mudanças de lifecycle em integrações e recursos do Copilot, reforçando a necessidade de acompanhar tooling como dependência de plataforma.

## Sinal da edição

O ecossistema .NET começa a tratar agentes como parte normal do toolchain de desenvolvimento.
