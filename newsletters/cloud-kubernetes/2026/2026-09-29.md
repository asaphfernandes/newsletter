# Cloud + Kubernetes — Resumo semanal — 29/09/2026

## Kubernetes CVE patches

Versões 1.34.12, 1.35.9, 1.36.5 e 1.37.1 corrigiram problemas incluindo confused deputy em StatefulSet e falhas Windows relacionadas a subPath/UNC/NTLM.

## Service Bus: deadline de 30/09

SBMP e SDKs legados chegaram ao fim do suporte; migração para SDK moderno/AMQP tornou-se urgente.

## AKS VMAS auto-migration

A Microsoft passou a mover clusters antigos para modelos mais modernos de node pool.

## Envoy Gateway 1.9.2 / 1.8.5

Correções reforçaram a necessidade de manter gateways de produção dentro do ciclo suportado.

## Terraform 1.16

Destroy actions, import em child modules, JSON e Mermaid ampliaram automação e visualização de infraestrutura.

## containerd 1.7 EOL

O fim de suporte exige atualização para evitar runtime sem patches.

## Istio 1.31.1 e EOL 1.29

Service mesh continua exigindo disciplina de lifecycle.

## Sinal da edição

Prioridade operacional: **Service Bus, patches Kubernetes, AKS e runtimes fora de suporte**.
