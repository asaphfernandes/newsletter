# Cloud + Kubernetes — Resumo semanal — 13/10/2026

**Janela:** 06 a 13/10/2026, manhã de Brasília. Destaques: Azure API Management, AKS, Dapr, GitOps, gateways, observabilidade e segurança.

## 1. API Management: mudança obrigatória de rede até 30/11

**07/10.** A Microsoft está ampliando os endereços do plano de gerenciamento do APIM. Os **tiers clássicos v1 em VNet internal/external** devem substituir listas fixas de IP pela **service tag ApiManagement** em NSGs, UDRs e firewalls, quando suportado.

**Técnico:** sem ajuste até **30/11/2026**, a administração de APIs, operações e policies via portal/CLI pode falhar, embora o tráfego de execução não seja diretamente afetado. **Operação:** inventariar gateways e testar conectividade do control plane. **Custo:** impacto indireto de indisponibilidade administrativa.

[Fonte: Microsoft — API Management service tag](https://techcommunity.microsoft.com/blog/integrationsonazureblog/update-network-rules-for-the-api-management-service-tag/4562518).

## 2. Dapr 1.18.6/1.18.7: isolamento e concorrência

**09/10.** A versão **1.18.6** corrigiu identidade de chamada falsificável em headers, brechas em reminders de atores internos, interpretação de paths codificados em policies e possíveis resultados falsificados de workflows. A **1.18.7** corrigiu crashes, data races, atividades retidas e problemas de requisições simultâneas.

**Técnico:** aplicações que confiam em headers de origem para autorização precisam de identidade autenticada; as próprias policies do Dapr baseadas em mTLS não dependiam dos headers afetados. **Operação:** atualizar sidecars de modo consistente e testar invocation, workflows, atores e pub/sub. **Custo:** menos reinícios e falhas; exige regressão.

[Fontes: Dapr 1.18.6](https://github.com/dapr/dapr/releases/tag/v1.18.6) · [Dapr 1.18.7](https://github.com/dapr/dapr/releases/tag/v1.18.7).

## 3. AKS: NAT Gateway gerenciado StandardV2 em GA

**08/10.** Novos clusters com **managedNATGateway**, rede gerenciada pelo AKS e API **2026-06-01+** usam **StandardV2** por padrão nas regiões compatíveis. Inclui egress redundante por zona, maior throughput e suporte a IPv6.

**Técnico:** StandardV2 exige IPs públicos/prefixos também StandardV2. **Operação:** clusters Standard existentes não migram automaticamente; upgrade é permitido, downgrade não. Checar egress IP, allowlists e região. Não aplicar pressupostos de rede gerenciada a VNets customizadas. **Custo:** comparar SKU, IPs e tráfego, sem presumir economia.

[Fontes: Azure Updates](https://azure.microsoft.com/en-us/updates?id=574430) · [Microsoft Learn — NAT Gateway](https://learn.microsoft.com/en-us/azure/aks/nat-gateway).

## 4. GitOps com Argo CD gerenciado para AKS está em GA

**07/10.** A extensão para AKS integra Entra ID, workload identity, acesso a serviços Azure, métricas no Azure Managed Prometheus e administração por portal, CLI e Terraform.

**Técnico:** simplifica gestão de GitOps e integração de identidade. **Operação:** comparar com Argo CD self-managed, revisar ApplicationSets, RBAC, ciclo de upgrade e disaster recovery. A **GA é para AKS**; não confundir com Arc genérico. **Custo:** contabilizar telemetria e recursos contra esforço operacional evitado.

[Fonte: Microsoft — GitOps with Argo CD for AKS](https://techcommunity.microsoft.com/blog/AzureArcBlog/gitops-with-argo-cd-extension-for-aks-is-now-generally-available/4562231).

## 5. Agent 365 + API Management: governança MCP (preview)

**09/10.** Integração descobre servidores MCP no APIM e permite bloqueio pelo Agent 365. **Tiers v2** oferecem inventário/bloqueio no nível do servidor; **AI Gateway (preview)** acrescenta bloqueio por ferramenta, telemetria e inspeção com Defender/Purview.

**Técnico:** governança central e enforcement no gateway são camadas distintas da autorização de dados nos backends. **Operação:** bloquear acesso direto ao servidor MCP, avaliar consentimentos e limitações de preview. **Custo:** tiers, serviços de segurança e logs.

[Fontes: Microsoft — integração](https://techcommunity.microsoft.com/blog/integrationsonazureblog/microsoft-agent-365-and-azure-api-management-integration-for-mcp-governance/4563335) · [Microsoft Learn — limitações](https://learn.microsoft.com/en-us/azure/api-management/agent-365).

## 6. Azure Arc: EKS/GKE via Multicloud Connector (preview)

**07/10.** O Multicloud Connector ganhou fluxo de descoberta e onboarding de clusters EKS/GKE para gestão via Arc, com possibilidades de Azure Policy, Defender e Monitor.

**Operação:** validar credenciais, instalação de agentes, egress, suporte regional e limites do preview. **Custo:** cuidado com telemetria e segurança duplicadas entre nuvens.

[Fonte: Microsoft — Arc Multicloud Connector](https://techcommunity.microsoft.com/blog/AzureArcBlog/public-preview-onboard-kubernetes-clusters-to-azure-arc-with-the-multicloud-conn/4556330).

## 7. Gateway API 1.7.0-rc.1: retries e telemetria

**08/10 — release candidate.** Configuração de retry em HTTPRoute avança para canal Standard da especificação candidata. O tracing via **XTelemetryPolicy** é experimental; suporte, backoff e detalhes variam por controller.

**Operação:** verificar conformance; não implantar RC como GA nem permitir retries sem limites, evitando amplificação de carga. **Custo:** chamadas repetidas e tracing consomem recursos.

[Fonte: Kubernetes Gateway API v1.7.0-rc.1](https://github.com/kubernetes-sigs/gateway-api/releases/tag/v1.7.0-rc.1).

## 8. Envoy: patches e quantis de Prometheus

**12/10.** Publicadas versões **1.39.4, 1.38.7 e 1.37.9**. A linha 1.39.4 corrige races em mudanças RDS de configuração por rota e erro de bucket em native histograms introduzido em 1.38.0, que podia **subestimar quantis**.

**Operação:** mapear versão no ingress/mesh, aplicar patch compatível, testar atualizações dinâmicas de rotas e reavaliar painéis p95/p99. **Custo:** correção de métricas ajuda a evitar decisões ruins de capacidade.

[Fontes: Envoy 1.39.4](https://github.com/envoyproxy/envoy/releases/tag/v1.39.4) · [Envoy 1.38.7](https://github.com/envoyproxy/envoy/releases/tag/v1.38.7).

**Operação:** avaliar atualização especialmente em instalações com CMP/OCI; observar drift e memória. **Custo:** menos investigações e consumo anormal.

## 10. OPA 1.21.2: atualização de segurança

**Operação:** aplicar atualização após testes de policies e caminhos percent-encoded, considerando proxies reversos. **Custo:** esforço de patching para reduzir risco de bypass.

[Fonte: Open Policy Agent 1.21.2](https://github.com/open-policy-agent/opa/releases/tag/v1.21.2).

**Operação:** inventariar extensão usada, migrar com workload identity e revisar RBAC, rotação e sincronização offline. **Custo:** planejar migração para evitar risco de suporte.

[Fontes: Azure Updates](https://azure.microsoft.com/en-us/updates?id=570313) · [Microsoft Learn — Secret Store](https://learn.microsoft.com/en-us/azure/azure-arc/kubernetes/secret-store-extension).
