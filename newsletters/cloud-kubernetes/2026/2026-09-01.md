# Cloud + Kubernetes — Resumo semanal — 01/09/2026

Janela principal: última semana de agosto até 01/09/2026.

## Kubernetes 1.37

A edição acompanhou a nova versão do Kubernetes e suas mudanças para produção.

## HPA scale-to-zero

Evoluções em autoscaling aproximaram workloads Kubernetes de cenários de elasticidade mais agressiva. **Trade-off:** economia de capacidade versus latência de cold start.

## Pod Certificates

Identidade de workload ganhou novas primitives para emissão e rotação de certificados por Pod.

## Metrics API

Mudanças na camada de métricas reforçaram a integração entre autoscaling e observabilidade.

## Storage Version Migration

O recurso foi destacado por facilitar evolução segura de versões armazenadas no etcd durante upgrades.

## APIM + Service Bus GA

Integração mais direta entre Azure API Management e Azure Service Bus entrou em GA.

## APIM Zone Redundancy

Melhorias de disponibilidade permitiram desenhos mais resilientes para gateways de API.

## Azure Multicloud Interconnect

O serviço ampliou opções de conectividade privada entre Azure e outros ambientes de cloud.

## Sinal da edição

Identidade, elasticidade e conectividade continuam migrando para primitives gerenciadas da plataforma.
