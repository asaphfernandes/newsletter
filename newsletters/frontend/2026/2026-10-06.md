# Front-end — Resumo semanal — 06/10/2026

Janela principal: **29/09 a 06/10/2026**. A semana teve menos movimento em releases de React, TypeScript, Vite ou Next.js e mais mudanças relevantes em **segurança de frameworks full-stack, Web APIs, runtime, performance e supply chain JavaScript**.

## TanStack Start corrige XSS crítico em Server Functions

Uma vulnerabilidade crítica e não autenticada de XSS refletido envolvendo o transporte de Server Functions foi corrigida.

O ponto arquitetural é que frameworks full-stack transformam chamadas aparentemente locais em um protocolo distribuído.

```text
React Component
      ↓
Server Function
      ↓
serialization / transport
      ↓
middleware
      ↓
server execution
```

Esse boundary precisa ser tratado como uma **API exposta**, mesmo quando o framework abstrai HTTP, serialização e roteamento.

## A Web Platform absorve responsabilidades antes resolvidas pelo framework

Mudanças recentes incluem melhorias em responsive images, streaming, WebTransport e Static Routing API de Service Workers.

**Impacto:** parte do comportamento que antes exigia bibliotecas, bundlers ou JavaScript pode migrar para primitives nativas da plataforma.

## Firefox 157 melhora progressive enhancement e WebGPU

O Firefox adicionou suporte a `at-rule()` dentro de `@supports`, facilitando feature detection declarativo de recursos CSS.

Também houve melhoria de eficiência no WebGPU com attachments transitórios.

## Vercel passa a bloquear novos deploys em Node.js 20

Projetos configurados para Node.js 20 precisam migrar para versões suportadas.

**Impacto arquitetural:** versão de Node deve ser propriedade controlada da plataforma de desenvolvimento, alinhando local, CI e produção.

## FID sai de cena; performance deve olhar para INP

A migração de FID para **Interaction to Next Paint (INP)** reforça que responsividade deve ser medida durante toda a sessão.

Em SPAs React, long tasks, hydration, event handlers, JSON parsing e state updates amplos podem degradar INP.

## Incidente no ecossistema SubQuery reforça supply-chain security

Um pacote comprometido podia alcançar aplicações por dependências transitivas.

**Impacto:** package.json, lockfile, registry, CI runner, build e artefato de produção formam uma única cadeia de supply chain.

## ESLint 10.12 melhora tooling baseado em AST

Mudanças de tipagem em `SourceCode` beneficiam organizações que usam ESLint como plataforma para enforcement arquitetural, como restrições de import e boundaries entre módulos.

## Watchlist: browser começa a oferecer primitives hoje pertencentes ao bundler

Text module imports e `import defer` apontam para um futuro em que parte do trabalho de loaders e transformações pode virar semântica nativa da Web Platform.

## Sinal da semana

Front-end Architecture inclui explicitamente **runtime, segurança de dependências, CI/CD, protocolo entre cliente e servidor e observabilidade de performance**.
